OpenRBI is a free HTML (web page) using your file system and records to build your own risk-based inspection platform designed to support engineers, inspectors and asset owners in order to carry out structured RBI assessments. It also feeds a knowledge-based AI system operating within the customer’s corporate ISO/IEC 42001 AI management system, which can link RBI findings and recommendations with planning AI. The applications bring equipment data, degradation mechanisms, inspection history, probability of failure, consequence assessment, risk ranking and inspection planning together in one practical workflow.

OpenRBI uses a composable software architecture. The platform is assembled from independent, interchangeable pieces rather than one large, fixed application. Any part of the workflow can be built, replaced, upgraded or extended using an OpenRBI model suited to that function. These models operate like plug-and-play components, allowing organisations to adopt only the capabilities they need and to replace individual components without rebuilding the entire platform. A composable software architecture uses independent, modular building blocks that link together via APIs to create custom systems. A compostable 

This architecture also allows OpenRBI to evolve as engineering methods, standards, organisational requirements and AI capabilities change. An equipment-data module, degradation model, probability model, consequence model, inspection-planning tool or AI interface can be updated independently while the remaining parts of the system continue to use the established project-file structure.

OpenRBI processes information locally within the user’s browser. 

There are no user accounts. 

no per seat fees

no subscription fees 

No external databases are required.

All files remain under the user’s control and can be stored within existing company systems such as SharePoint, OneDrive or local network storage. The file-based architecture also allows information to move between OpenRBI applications, corporate knowledge systems and authorised planning AI without making OpenRBI the organisation’s system of record.

OpenRBI is intended to make risk-based inspection more accessible, transparent and practical, particularly for organisations and engineers who need capable engineering tools without the cost and complexity of traditional enterprise software.

OpenRBI is a proof-of-concept engineering tool provided for screening, education and calculation support. It is not certified or approved software. Its inputs, assumptions, calculations and outputs must be reviewed by a competent engineer, inspector, owner-user or statutory authority, as required.
