Fulcrum (Data Organiser)

          This is the data organiser, you can use this web version if you want and just save the analysis and reload next time or you can save the whole of the html file.  Then you can keep all of your data            on your system the choice is yours.  It does not store data it only links to your system where the reports are.  No data is stored on the website so save everything you do, like word or excel you                have to save and load your data everytime you work on it.  If you pick any Asset you will see in the centre of the screen an "Export data to RBI" (save this file) this exports the basic data from                  fulcrum ready for import into RBI analysis.
